# Temporal Link Prediction for Dynamic Network Analysis

## Abstract
This study, conducted as a term project for the CSE 474 / CSE 5074 Social Network Analysis course at Akdeniz University, addresses the task of Temporal Link Prediction. The goal is to predict the probability of an edge forming between two nodes within a future time interval. A Temporal Graph Neural Network (TGNN) architecture was designed and trained using PyTorch Geometric. The methodology involved preprocessing temporal graph data, implementing various GNN architectures, and evaluating model performance based on AUC metrics. Our best model achieved a validation AUC of 0.8775 across temporal windows and displayed high confidence in test predictions.

**Index Terms:** Temporal Link Prediction, Graph Neural Networks, PyTorch Geometric, Dynamic Graphs, Temperature Scaling

## I. Introduction

Temporal link prediction refers to the task of forecasting future connections or interactions between nodes in a time-evolving network. This prediction is critical in domains such as recommendation systems, fraud detection, social network analysis, and temporal knowledge graphs. Unlike static approaches, temporal models account for the evolution of node states and relationships over time, which allows more accurate and timely predictions.

Temporal Graph Neural Networks are designed to tackle such problems by maintaining temporal information for nodes and enabling the model to capture interaction histories. These mechanisms are especially important when working with high-frequency or sparse interaction data, as they allow the model to learn patterns that develop over time.

This report presents the preprocessing, architecture design, training strategy, and results of applying three custom GNN architectures to temporal data. We investigate the capabilities of each model and identify the most effective approach for temporal link prediction.

## II. Data Overview

The datasets used in this project consist of a temporal event graph with the following components:

- **edges_train_A.csv**: Temporal edge list with source node ID, destination node ID, and timestamp.
- **node_features.csv**: Node-level features for each node in the graph.
- **edge_type_features.csv**: Features corresponding to each edge type.
- **output_A.csv**: Predicted probabilities generated by the trained model.

Several transformations were applied to prepare the data:
- Node and edge IDs were mapped to contiguous integer indices for tensor-based computation
- Data was organized into temporal windows to preserve sequential information
- Features were normalized and processed to ensure compatibility with PyTorch models

## III. Methodology

### A. Preprocessing

The following steps were applied to prepare the data:

1. Edge data was loaded and processed to create a temporal graph structure
2. Node features were loaded and associated with each node in the graph
3. Edge type features were incorporated into the edge representations
4. The temporal data was divided into multiple time windows to enable training across temporal snapshots
5. For each time window, training and validation sets were created with negative sampling

### B. Model Architectures

We implemented three distinct model architectures:

1. **TemporalGCN**: A baseline architecture that uses Graph Convolutional Network layers
   - Features skip connections for improved gradient flow
   - Dropout regularization to prevent overfitting
   - Multiple GCN layers for hierarchical feature learning

2. **EdgeTemporalGNN**: An architecture focusing on edge features
   - Transformer convolutional layers with multi-head attention
   - Dedicated encoders for both node and edge features
   - A specialized link predictor module

3. **TGNNModel**: The most comprehensive temporal architecture
   - Time encoder module to process temporal information
   - Memory mechanism to preserve node state across time windows
   - Advanced message passing to propagate temporal information

Our experiments found that the TGNNModel performed best for this task, achieving consistent AUC scores across temporal windows.

### C. Training Process

The training configuration was as follows:
- Optimizer: Adam
- Loss Function: Binary Cross-Entropy
- Epochs: 5 per time window
- Temperature Scaling: 5.0 for prediction normalization
- Device: CPU (with GPU option available)

We implemented a sliding window approach where the model was trained on sequential temporal snapshots. For each window, we:
1. Prepared the relevant subset of data
2. Trained the model for the specified number of epochs
3. Evaluated on a validation set
4. Saved the model with the best performance

## IV. Experimental Results

The TGNNModel showed consistent performance across temporal windows:

- Time Window 1: Val AUC = 0.8704
- Time Window 2: Val AUC = 0.8775 (Best performance)
- Time Window 3: Val AUC = 0.8704
- Time Window 4: Val AUC = 0.8655
- Time Window 5: Val AUC = 0.8592

The best model (from time window 2) was saved and used for generating test predictions. These predictions demonstrated high confidence, with many values at 0.99 after temperature scaling. This suggests the model is very certain about its predictions, which is a common outcome when using temperature scaling with a value of 5.0.

### Implementation Challenges

During development, we encountered and addressed several challenges:
1. The GCN model implementation had interface compatibility issues, causing errors when passing certain parameters
2. Initial prediction values were excessively extreme (near 0 or 1), which we addressed using temperature scaling
3. Memory management was crucial when processing large temporal graphs

## V. Discussion

The high prevalence of 0.99 predictions in our output file indicates strong model confidence. This is influenced by:

1. The temperature scaling parameter (5.0), which normalizes raw logits
2. The model's effectiveness in learning patterns from the temporal data
3. The potential simplicity of certain prediction tasks in the test set

While high confidence can indicate a well-trained model, it may also suggest potential overconfidence. Future work could explore:
- Adjusting the temperature parameter for more diverse prediction scores
- Implementing uncertainty quantification methods
- Exploring more complex architectures that can capture subtle temporal patterns

## VI. Conclusion

This project successfully implemented and evaluated multiple temporal graph neural network architectures for link prediction. The TGNNModel demonstrated the best performance with validation AUC scores around 0.87. The system provides a flexible framework for temporal link prediction that can be extended and refined for various applications.

Our implementation allows easy configuration of model architecture, training parameters, and prediction confidence through a unified command-line interface. Future improvements could focus on enhancing prediction diversity, incorporating additional temporal features, and optimizing the architecture for specific application domains.

## Usage Guide

The project can be used with the following commands:

1. **Training mode:**
   ```
   python run.py --mode train --model tgnn --epochs 5
   ```

2. **Testing mode:**
   ```
   python run.py --mode test --model tgnn
   ```

3. **Parameters:**
   - `--model`: Model type (tgnn, edge_gnn, gcn)
   - `--epochs`: Number of training epochs
   - `--hidden_dim`: Hidden dimension size
   - `--temperature`: Temperature scaling for predictions
   - `--cuda`: Use CUDA if available
